Artículo 180.- Por las autorizaciones para la realización de obras en bienes inmuebles considerados monumentos históricos o artísticos, en inmuebles colindantes a esos monumentos, en edificaciones en zonas de monumentos históricos declarados, se pagarán derechos conforme a las siguientes cuotas:
I.- Autorización para la realización de obra nueva:
a).- Para casa habitación y escuelas ... $36.00
b).- Para conjuntos de departamentos, la cuota del inciso anterior y además, por cada unidad ... $36.00
c).- Para conjunto de casas las cuotas de los incisos a) y b) y además, por cada unidad ... $180.00
d).- Para edificios de oficinas o mixtos ... $45.00
e).- Para edificios industriales, bodegas, talleres, fábricas o servicios de automóviles y estacionamientos ... $55.00
f).- Para restaurantes, hoteles, hospitales, teatros y cines ... $55.00
g).- Para conjuntos comerciales, supermercados, cabarets y similares ... $90.00
II.- Autorización para demolición, ampliación, modificación, restauración o rehabilitación, reestructuración y prórrogas de licencia:
a).- Para demolición ... $18.00
b).- Para ampliación ... $55.00
c).- Para modificación ... $55.00
d).- Cualquier caso de obra no especificado ... $55.00
III.- Autorización para la fijación de anuncios:
a).- Adosados al muro ... $18.00
b).- En saliente ... $56.00
c).- Cualquier caso de anuncio no especificado ... $55.00
